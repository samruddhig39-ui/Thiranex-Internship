# Thiranex Internship - Task 1
## Sales & Revenue Analysis Dashboard

### Project Overview

This project was developed as part of my Thiranex Data Analytics Internship.

The objective was to build an interactive Power BI dashboard to analyze sales and revenue performance.

### Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Total Orders KPI
- Sales Trend by Year
- Sales by Category
- Sales by Region
- Top Products by Sales
- Category slicer
- Region slicer
- Order Date filter

### Tools Used

- Power BI
- Data Analysis
- Data Visualization

### Key Insights

- Technology recorded the highest sales among the product categories.
- West region recorded the highest sales among the regions.
- Sales showed an overall upward trend after 2015.
- Top-performing products contributed significantly to overall sales.
- Interactive filters allow analysis by category, region and date.

### Outcome

The dashboard provides an interactive view of sales performance and helps identify trends, high-performing categories, regions and products.
